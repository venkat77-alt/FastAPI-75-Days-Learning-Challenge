# FastAPI 75 Days Learning Challenge 🚀

A hands-on 75-day journey focused on learning and building with Python and FastAPI.

This repository documents my progress as I work through FastAPI backend engineering concepts, implement them through practical coding, and gradually move toward building structured and production-oriented backend applications.

The goal of this challenge is simple:

> Learn the concept → Implement it → Test it → Understand it → Improve it

---

## 🎯 Why I'm Doing This Challenge

I wanted to move beyond simply learning backend concepts theoretically.

Throughout this challenge, I am focusing on:

- Understanding the fundamentals behind FastAPI and Python backend development
- Writing the code myself and learning through implementation
- Building APIs and testing them practically
- Understanding how different backend components work together
- Improving code organization and development practices
- Gradually moving from fundamentals to more advanced backend engineering concepts

This repository serves as a public record of that learning process.

---

## 🛠️ Technology Focus

The roadmap gradually covers technologies and concepts including:

---

## 📚 Learning Approach

Each day is approached with a practical mindset.

### 1. Understand

First, I study the concept and understand why it is used.

### 2. Implement

I write practical code based on the concept instead of relying only on theoretical examples.

### 3. Run & Test

I run the application and verify the behavior through API testing tools such as Swagger UI where applicable.

### 4. Review

I review what I implemented, identify areas that can be improved, and document the important lessons from the day.
